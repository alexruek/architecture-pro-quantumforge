# Задание 2. Подготовка базы знаний

## Какая вселенная взята за основу

За основу взята вселенная Star Wars, источник - starwars.fandom.com. Причина выбора: это широко известный фандом, который почти наверняка присутствует в обучающих данных большинства LLM, поэтому он хорошо подходит для проверки честности работы RAG-пайплайна.

## Логика подмены терминов

1. Отобрано 32 сущности из четырех категорий: персонажи, планеты, технологии и объекты, организации и расы, события.
2. Для каждой сущности написан отдельный документ на 100-200 слов в свободном изложении, без дословного цитирования какого-либо источника.
3. Составлен словарь соответствий terms_map.json: оригинальное название вселенной Star Wars сопоставлено с вымышленным аналогом из новой условной вселенной "Хроники Феррона".
4. Скрипт replace_terms.py проходит по каждому документу и заменяет все вхождения терминов из словаря, включая основные словоформы (падежи, множественное число), чтобы в тексте не осталось узнаваемых имен, названий планет, технологий и организаций.
5. Итоговые файлы сохраняются в папку knowledge_base/ и переименовываются по новому вымышленному названию сущности, чтобы даже путь к файлу не выдавал исходный источник.
6. После замены выполняется автоматическая проверка: по всем файлам knowledge_base/ ищутся оставшиеся вхождения оригинальных терминов (в разных словоформах). Итог проверки - 0 совпадений.

## Почему база знаний не может быть "угадана" по памяти модели

Модель может помнить факты о вселенной Star Wars, но:

- имена персонажей заменены на вымышленные (Дарт Вейдер стал Ксарн Велгор, Люк Скайуокер стал Дэйн Кориэл и так далее);
- названия планет, технологий, организаций и рас также заменены;
- сюжетные связи и структура повествования сохранены, но без оригинальных названий модель не может напрямую сопоставить документ с известным ей материалом и обязана опираться только на текст, найденный через поиск по векторному индексу.

## Структура проекта задания 2

```
task2/
  raw/                      исходные документы до замены терминов (32 файла + индекс)
  knowledge_base/           итоговая анонимизированная база знаний (32 файла)
  terms_map.json            словарь соответствий терминов
  scripts/
    generate_raw_docs.py    генерация исходных документов
    replace_terms.py        замена терминов и формирование knowledge_base/
    download_pages.py       шаблон скрипта скачивания страниц с вики (requests + BeautifulSoup)
  docs/
    README_zadanie2.md      этот файл
    verification_zadanie2.md пошаговая проверка результата
```

## Важное примечание про download_pages.py

Скрипт download_pages.py - рабочий шаблон для скачивания страниц напрямую с fandom-вики через requests и BeautifulSoup. Он используется, когда есть прямой доступ в интернет к домену fandom.com.

В условиях учебной песочницы, где готовился этот пакет файлов, доступ к внешним доменам ограничен и fandom.com не входит в список разрешенных. Поэтому исходные документы (raw/) подготовлены альтернативным способом - через generate_raw_docs.py, на основе общеизвестных фактов о вселенной, без обращения к конкретной странице вики и без копирования чужого текста. Результат эквивалентен по формату и объему: 32 отдельных документа по сущностям, готовых к дальнейшей анонимизации тем же способом, что описан в задании.

Если у вас есть доступ в интернет, можно donwload_pages.py запустить напрямую и получить raw-документы из реальных страниц вики, после чего пропустить их через тот же replace_terms.py.

## Установка зависимостей

```bash
python -m venv .venv
source .venv/bin/activate
pip install requests beautifulsoup4
```

## Порядок запуска скриптов

```bash
cd scripts

# шаг 1, только если есть доступ в интернет к fandom.com
python download_pages.py

# шаг 2, генерация исходных документов (если download_pages.py не запускался)
python generate_raw_docs.py

# шаг 3, замена терминов и формирование итоговой базы знаний
python replace_terms.py
```
