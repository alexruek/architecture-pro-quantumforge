# Задание 2. Подготовка базы знаний

## Какая вселенная взята за основу

За основу взята вселенная Star Wars, источник - starwars.fandom.com. Это широко известный фандом, который наверняка есть в обучающих данных большинства LLM, поэтому он хорошо подходит для проверки: если бот отвечает по памяти модели, а не по найденным чанкам, это сразу заметно.

В базе знаний вселенная превращена в вымышленную - "Хроники Феррона".

## Логика подмены терминов

1. Отобрано 32 сущности: 10 персонажей, 7 планет, 7 технологий и объектов, 4 организации, 1 раса, 3 события.
2. Для каждой сущности подготовлен отдельный документ примерно на 60-120 слов: краткий пересказ своими словами, без копирования страниц вики. Исходные тексты лежат в raw/, список - в raw/_index.json.
3. Составлен словарь terms_map.json. Раздел terms - основные соответствия (исходное название и вымышленное), раздел forms - падежные формы и короткие варианты имен ("Люк", "альянса", "световым мечом").
4. Скрипт scripts/replace_terms.py заменяет термины в каждом документе и сохраняет результат в knowledge_base/ под именем по вымышленному названию сущности (01_ksarn_velgor.md), чтобы даже путь к файлу не выдавал источник.
5. После замены скрипт сам проверяет базу и завершается с кодом 1, если нашел остатки исходных терминов или испорченные слова.

Правила замены:

- ключи применяются по убыванию длины: сначала "Люк Скайуокер", потом "Люк";
- термин заменяется только как отдельное слово. Короткий ключ "Хот" не затрагивает слово "охотник", а "Сила" - слово "силами";
- для слов, которые совпадают с обычными словами языка ("Сила"), регистр учитывается: "Сила" с заглавной буквы - термин вселенной, "сила" со строчной - обычное слово. Список таких ключей - в _meta.case_sensitive словаря;
- уже замененный фрагмент повторно не обрабатывается, поэтому вымышленные названия не могут попасть под другой ключ.

Русские падежи не выводятся автоматически: вымышленное название часто склоняется иначе, чем исходное ("Сила" женского рода, "Синт-Поток" мужского). Поэтому каждая встречающаяся форма записана в словаре явно.

| Дарт Вейдер | Ксарн Велгор |

| Галактическая Империя | Звездная Гегемония |

## Почему базу нельзя "угадать" по памяти модели

- имена персонажей, названия планет, технологий, организаций и рас заменены вымышленными;
- тексты - пересказы, а не цитаты, дословных совпадений с вики нет;
- сюжетные связи сохранены, поэтому ответы остаются осмысленными, но получить их можно только из найденных чанков.

## Состав папки knowledge_base

- 32 документа по сущностям (результат replace_terms.py);
- 33_zlonamerennyy_dokument.md - документ с промпт-инъекцией для задания 5;
- 34_kashrim.md - документ, добавленный для проверки обновления индекса в задании 6;
- _replacement_report.json - отчет о числе замен по каждому файлу.

Три документа перенесены в kb_removed/ для задания 7 (см. docs/README_zadanie7.md).

## Скрипты

| Скрипт | Назначение |
| --- | --- |
| scripts/download_pages.py | скачивание страниц вики (requests и BeautifulSoup) с очисткой от HTML, нужен доступ к fandom.com |
| scripts/generate_raw_docs.py | формирует raw/ из пересказов, записанных в самом скрипте |
| scripts/replace_terms.py | замена терминов, формирование knowledge_base/, проверка результата |

## Порядок запуска

```bash
python scripts/generate_raw_docs.py
python scripts/replace_terms.py
```

Ожидаемый вывод второго скрипта:

```
Обработано файлов: 32
Всего замен: 141
Проверка базы: исходных терминов и испорченных замен не найдено
```

Правила замены покрыты автотестами tests/test_replace_terms.py:

```bash
python -m unittest discover -s tests -v
```
