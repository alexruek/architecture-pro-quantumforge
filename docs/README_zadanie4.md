# Задание 4. RAG-бот с few-shot и Chain-of-Thought

RAG-бот отвечает на вопросы по базе знаний "Хроники Феррона". Пайплайн: поиск по векторному индексу FAISS, отсечение нерелевантных и подозрительных чанков, сборка промпта с few-shot примерами и инструкцией рассуждать по шагам (Chain-of-Thought), генерация ответа со списком источников. Если релевантных данных нет, бот отвечает, что не знает ответа.

Бот использует результаты предыдущих заданий: knowledge_base/ и terms_map.json из задания 2, индекс faiss_index/ из задания 3.

## Структура

```
knowledge_base/        база знаний (задание 2)
faiss_index/           индекс FAISS (задание 3)
src/
  config.py            настройки: пути, модели, порог релевантности
  embeddings_factory.py  модель эмбеддингов
  prompts.py           системный промпт (CoT) и few-shot примеры
  rag_pipeline.py      ядро RAG: поиск, сборка контекста, вызов LLM
  cli.py               консольный интерфейс
  app.py               REST API на FastAPI
scripts/
  tune_threshold.py    подбор порога релевантности
  make_examples.py     формирование examples_dialogs.md
examples_dialogs.md    примеры диалогов
.env.example           шаблон переменных окружения
```

## Как устроен пайплайн

1. Вопрос преобразуется в эмбеддинг той же моделью, что использовалась при индексации.
2. Из индекса извлекаются TOP_K ближайших чанков, чанки с оценкой ниже RELEVANCE_THRESHOLD отбрасываются.
3. Если релевантных чанков не осталось, бот возвращает фразу "Я не знаю ответа на этот вопрос по имеющейся базе знаний." без обращения к LLM.
4. Чанки проверяются на признаки промпт-инъекции (задание 5), подозрительные исключаются из контекста.
5. Контекст с указанием источников, системный промпт и два few-shot примера собираются в промпт по шаблону из src/prompts.py.
6. LLM генерирует ответ, бот возвращает его вместе со списком источников и статусом (answered, refused, blocked или error).

## Техники промптинга

Few-shot. В промпт добавлены два примера в формате "вопрос - рассуждение - ответ". Оба взяты из текстов базы: о дроиде, который хранил похищенные чертежи (22_droid_t2_d9.md), и о цветах клинков (19_plazmennyy_klinok.md). Эти вопросы не входят ни в серию задания 5, ни в золотой набор задания 7, чтобы примеры не подсказывали ответы на проверочные вопросы. Соответствие примеров текстам базы проверяет автотест tests/test_replace_terms.py.

Chain-of-Thought. Системный промпт требует сначала кратко расписать ход рассуждения по шагам, опираясь только на контекст, затем дать итоговый ответ одной-двумя фразами, а при отсутствии данных честно написать, что ответа нет.

## Порог релевантности

Оценки релевантности у разных моделей эмбеддингов лежат в разных диапазонах, поэтому порог подбирается под модель, а не переносится. Скрипт scripts/tune_threshold.py без вызова LLM считает оценки для вопросов золотого набора (ожидаемый документ должен пройти порог) и для вопросов вне базы (ни один чанк не должен пройти) и выбирает середину интервала, который разделяет эти группы:

```bash
python scripts/tune_threshold.py            # таблица оценок и рекомендация
python scripts/tune_threshold.py --apply    # записать порог в src/config.py
```

## Запуск

Нужны Python 3.11 и доступ в интернет для первой загрузки модели эмбеддингов (около 470 МБ, дальше используется локальный кеш Hugging Face).

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # вписать OPENAI_API_KEY
python src/cli.py
```

На вопрос "Кто такой Хоррак?" бот возвращает рассуждение, ответ и строку "Источники:" с файлами из knowledge_base. На вопрос "Какая сейчас погода в Хельсинки?" - фразу о том, что не знает ответа.

## Режимы LLM

| Режим | Условие | Назначение |
| --- | --- | --- |
| gpt-4o-mini | в .env задан OPENAI_API_KEY | основной режим, выбран в задании 1 |
| google/flan-t5-base | ключа нет | локальный резервный вариант, около 1 ГБ |

Примеры в examples_dialogs.md и скриншоты получены на gpt-4o-mini. Модель flan-t5-base обучена преимущественно на английском языке: с ней пайплайн работает целиком, но на русских вопросах ответы короткие и без пошагового рассуждения.

## Интерфейсы

Консоль:

```bash
python src/cli.py
```

REST API:

```bash
uvicorn app:app --app-dir src
curl -X POST http://127.0.0.1:8000/ask -H "Content-Type: application/json" -d '{"question": "Кто такой Хоррак?"}'
```

POST /ask возвращает поля answer, sources, used_context и status, GET /health - {"status": "ok"}.

## Примеры диалогов

examples_dialogs.md формируется скриптом из реальных ответов бота, без ручной правки: пять вопросов по базе и два вопроса вне базы.

```bash
python scripts/make_examples.py
```

## Настройки

Значения по умолчанию заданы в src/config.py, переменные окружения и .env их переопределяют.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| EMBEDDING_MODEL_NAME | intfloat/multilingual-e5-small | модель эмбеддингов |
| INDEX_PATH | faiss_index | расположение индекса |
| TOP_K | 4 | число извлекаемых чанков |
| RELEVANCE_THRESHOLD | см. src/config.py | порог релевантности чанка, подбирается tune_threshold.py |
| OPENAI_MODEL_NAME | gpt-4o-mini | облачная LLM |
| LOCAL_LLM_MODEL_NAME | google/flan-t5-base | локальная LLM |
| PROTECTION_LEVEL | 3 | уровень защиты от промпт-инъекций (задание 5) |

Модель в EMBEDDING_MODEL_NAME должна совпадать с моделью, которой построен индекс. При смене модели update_index.py пересобирает индекс целиком, после этого порог нужно подобрать заново.
